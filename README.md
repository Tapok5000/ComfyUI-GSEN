## Установка

В папке `ComfyUI/custom_nodes`:

```bash
git clone https://github.com/Tapok5000/ComfyUI-MyNode
```

Или скачать [zip](https://github.com/Tapok5000/ComfyUI-MyNode/archive/refs/heads/main.zip) и распаковать в `custom_nodes/ComfyUI-MyNode`. Потом перезапустить ComfyUI.

Нужен ComfyUI 0.43.2 или новее, сторонние паки не нужны.

## Обновление

Krea2 One → ↗ Settings → **Update**  Потом перезапустить ComfyUI и нажать Ctrl+F5.

Системные промты для LLM  `face/prompts`
