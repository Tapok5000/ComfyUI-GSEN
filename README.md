# MyNode

Свои ноды для ComfyUI. Главная — **Krea2 One**: вырезка лица, AI-промт, Krea2 identity edit и RU/EN в одной ноде со своим интерфейсом.

## Установка

В папке `ComfyUI/custom_nodes`:

```bash
git clone https://github.com/Tapok5000/ComfyUI-MyNode
```

Или скачать [zip](https://github.com/Tapok5000/ComfyUI-MyNode/archive/refs/heads/main.zip) и распаковать в `custom_nodes/ComfyUI-MyNode`. Потом перезапустить ComfyUI.

Нужен ComfyUI 0.43.2 или новее, сторонние паки не нужны.

## Обновление

Krea2 One → ↗ Settings → **Update**: там версия пака и новая на GitHub, щелчок ставит новую. Потом перезапустить ComfyUI и нажать Ctrl+F5.

Свои системные промты для AI кладите в `face/prompts`: обновление их не трогает.

Что нового — в [CHANGELOG.md](CHANGELOG.md).
