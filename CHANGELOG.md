# Changelog

Версия пака — в `pyproject.toml`. Новая запись сверху при каждом изменении.

## 1.13.0 — 2026-11-14

- **Средняя панель по новому `MyNode.svg`**: поля PROMPT и RU выше, под ними короткие плашки **Resize** · ref_boost · grounding_px, ниже **custom / preset** · W · H, затем seed, steps, sampler и scheduler. Подписи лаймовые.
- **Resize** — бывшая строка resolution: on — размер из W × H или пресета, off — размер входной картинки (max_resolution его ограничивает).
- **custom / preset** — бывшая строка Format, переключается щелчком. custom — W и H; preset — на их месте плашка пресета: ◀ ▶ листают, щелчок по имени открывает список. Следующий щелчок по custom / preset возвращает к последнему пресету.
- **Settings по макету**: LLM (вкл/выкл AI-промта, бывшая строка AI), System, Crop и FaceCrop в одну строку, SAVE, Update внизу справа — короткими плашками. max_resolution и seed mode, которых в макете нет, стоят в свободном правом столбце.
- Сохранённые воркфлоу открываются как раньше: входы ноды те же.
- Update на ПК, где пак разрабатывается, пишет «версия · dev» и больше не обрезается.

## 1.12.0 — 2026-11-13

- **Сравнение A/B** под результатом: кнопки **Slide · A · B**, как в ausboss Image Compare A/B, только в стиле ноды. Slide — линия идёт за курсором: слева вход (A), справа результат (B); курсор ушёл — снова результат. A и B держат свою картинку. Режим сохраняется в воркфлоу, у каждой картинки пачки свой вход. Размеры и вид — по обновлённому `MyNode.svg`.
- **Модели в Settings**: у каждой цветная точка по типу — MODEL фиолетовая, LoRa зелёная, CLIP и LLM жёлтые, VAE красная. Точки стоят ровным столбиком, в том числе там, где в имени нет значка. Имена показываются без значков-эмодзи, полное имя видно при наведении. Модель, которой нет в папках, подсвечена красным.
- **Автопоиск моделей**: новая нода берёт самую новую версию (например, identity edit `v2`, а не `v1_2`). Воркфлоу с другого ПК: модель с чужим путём ищется по имени файла во всех папках models, включая extra_model_paths; не нашлась — берётся модель по умолчанию того же семейства; нет и её — строка красная. Что найдено, заменено или не найдено, пишет всплывашка.
- При открытых Settings часы в шапке больше не торчат из-под панели, как в макете.
- Nodes 2.0: панели доходят до низа ноды, пустой полосы 30 px больше нет.

## 1.8.0 — 2026-11-12

- **Crop** в Settings (по умолчанию off): своя обрезка входной картинки, как в ausboss Image Crop + Rotate + Pad, только в стиле ноды. С Crop on превью слева становится редактором:
  - лаймовая рамка с 8 ручками — что оставить: края и углы тянутся, саму рамку можно двигать;
  - ромбы и уголки снаружи — поля вокруг рамки, они заливаются серым;
  - кружок ↻ — поворот по часовой; с Shift шагами по 15°, у 0°, 90° и 180° прилипает;
  - внизу «crop 650×862 · 1:1.33 → 830×1042»: рамка, её пропорции и итог с полями. RESET сбрасывает всё.
- Обрезка идёт первой: Face Crop ищет лицо уже внутри неё, AI видит её, размер «по картинке» берётся от неё. Face Crop работает как раньше и включается отдельно.
- Обрезка помнится для своей картинки: стрелками на другую — та целиком, вернулся — рамка на месте.
- Новые входы `manual_crop` и `crop` — в конце, сохранённые воркфлоу открываются как раньше.

## 1.7.0 — 2026-11-09

- **LOAD TXT** над окном промта: открывает обычное окно выбора файла, промты из `.txt` загружаются в ноду. Над окном видно «TXT: 345.txt · 13 prompts», в окне — текст файла (только чтение). Run делает по картинке на каждый промт. **CLOSE TXT** возвращает обычный промт из окна.
- Как разделять промты в txt (подходят оба твоих файла):
  - строкой из чёрточек `---------` (от трёх `-`); тогда внутри промта можно делать абзацы и пустые строки;
  - если чёрточек в файле нет — пустой строкой.
- `<lora:имя:сила>` в промте (как в A1111) подключает эту LoRA только для его картинки, поверх основной и тех, что в Settings; из текста тег убирается. Имя ищется по имени файла в папке loras: без папок и `.safetensors`, регистр не важен. LoRA, которой нет, пропускается: пачка идёт дальше, а в углу появляется предупреждение со списком пропущенных. Теги работают и в обычном промте.
- Строка TXT с путём в Settings убрана: путь надо было вписывать руками, а просто имя искалось в папке `input`. Старое значение в сохранённых воркфлоу ничего не ломает.

## 1.1.0 — 2026-11-09

Логика FACE переделана один в один по воркфлоу `444.json`, интерфейс прежний.

- **CROP** (Settings, по умолчанию on): лицо вырезается из входа — масштаб 1280 по длинной стороне, RetinaFace, квадрат 1:1 с запасом ×2 — и идёт в LLM и в Krea2 как референс. Перенесено из AutoCropFaces + LayerStyle (MIT, `face/licenses/`), на 10 картинках совпадает с оригиналом попиксельно. При нескольких лицах берётся второе по уверенности (`start_index` 1, как в `444`).
- **AI** (Settings, по умолчанию off): on — LLM переписывает промт по картинке, и в семплер идёт он; off — промт как есть. Выключенная ветка не строится и не грузит LLM.
- Krea2 edit: пиксельный путь `fit` (картинка + VAE, референс по центру, шаг 1), источник кодируется до семплинга. С krea2edit совпадает бит в бит.
- RU — перевод итогового промта через Google, как в `444` (нужен интернет; без него в окне RU сообщение, картинка всё равно делается). Клик по подписи RU показывает EN — промт, который получил семплер.
- LLM грузится как `krea2`; по умолчанию `grounding_px` 1024 и LoRA `krea2_identity_edit_v1_2`, как в `444`.
- Новые входы `face_crop`, `ai_prompt` — в конце, сохранённые воркфлоу открываются.

## 1.0.0 — 2026-11-09

Пак собран в один набор и переписан под структуру «папка на ноду».

- **FACE Processing** (`MyNode_FaceProcessing`): весь воркфлоу `123.json` в одной ноде со своим интерфейсом по `MyNode.svg`.
  Krea2 identity edit (`ref_boost`, grounded encode), LLM-описание лица, сборка промта, перевод в RU локальной LLM.
- Работает на голом ComfyUI 0.44+: только ноды ядра и свои (`face/parts.py`), сторонние паки не нужны.
- Галерея картинок из `input/` с папками, фильтром и миниатюрами (`/mynode/images`, `/mynode/thumb`).
- Settings: модели, LoRA, CLIP, VAE, LLM, max_resolution, режим seed (fixed / randomize / increment / decrement).
- Ввод чисел: клик выделяет число целиком, новое заменяет его; значение применяется сразу.
